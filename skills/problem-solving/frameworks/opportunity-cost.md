# Opportunity Cost Analysis

## When this lens applies

Use when the operator is evaluating *whether to do something* in isolation -- a
new initiative, a hire, a partnership, a feature, a side project. The lens
forces the question they are *not* asking: "what am I giving up by doing this?"
Particularly useful when the operator's calendar, capital, or attention are
already near full.

## Prompt template

```
I want you to help me evaluate a commitment using Opportunity Cost
Analysis. Every time I say yes to something, I'm saying no to
everything else I could do with that time, money, or energy. I need
you to make those invisible tradeoffs visible.

For the commitment I describe, help me answer:
- What specifically am I giving up by doing this?
- What is the highest-value alternative use of the same resources?
- If I could only pick one, which option builds more long-term value?

Don't let me treat this as a yes/no decision. Frame it as a 'this
versus that' decision.

What I'm considering committing to: <COMMITMENT>
```

## What a strong answer looks like

- Reframes the question from "should I do X?" to "X versus <specific named
  alternative>" -- and names the alternative.
- Quantifies the resource pool being committed: hours per week, dollars,
  calendar weeks, one of N hire slots, etc. Vague "energy" is a tell that the
  lens hasn't bitten.
- Lists at least three alternative uses of the same resources, ranked by
  long-term value. The discarded alternatives are the point.
- Distinguishes *capital* opportunity cost (this dollar can't be used twice)
  from *attention* opportunity cost (this focus can't be split). They behave
  differently.
- Closes with the verdict: which of the named options builds more long-term
  value, and what the operator would have to believe for the other option to
  win.

## Failure modes to avoid

- Treating "do nothing" as the only alternative. That is rarely the real
  comparison; there's almost always a higher-value alternative use of the same
  resources.
- Vague tradeoffs ("you'd have less time for strategy"). Name the specific
  strategic project being crowded out.
- Ignoring compounding. A choice that consumes attention for 18 months has a
  much larger opportunity cost than the same dollar amount spent in a one-shot
  transaction.
- Recommending "do both" -- that's an evasion of the lens. If both are genuinely
  doable, the operator wasn't actually facing an opportunity cost problem.
